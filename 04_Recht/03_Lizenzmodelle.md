# Lizenzmodelle

## Grundlagen
Software ist durch das **Urheberrecht** (URG) geschützt. Mit dem Kauf erwirbt man nicht die Software selbst, sondern eine **Lizenz**, also ein Nutzungsrecht. Die Lizenz regelt, *wer* die Software *wie*, *wo* und *wie lange* nutzen, kopieren, verändern und weitergeben darf. Oft geschieht das über eine **EULA** (End User License Agreement).

## Proprietäre / kommerzielle Lizenzen
Der Quellcode ist **nicht** offen, Nutzung und Weitergabe sind eingeschränkt.

| Modell | Beschreibung | Beispiel |
|---|---|---|
| **Einzelplatz / Kauflizenz** (perpetual) | Einmal bezahlt, unbegrenzt nutzbar (Updates oft nicht inbegriffen) | Office 2024 Home, ältere Spiele |
| **Abonnement / Subscription** | Laufende Gebühr, die Nutzung endet mit dem Abo | Microsoft 365, Adobe Creative Cloud |
| **SaaS** | Software läuft in der Cloud, bezahlt wird pro Benutzer und Monat | Salesforce, Google Workspace |
| **Volumenlizenz** | Für Organisationen, viele Installationen zu Rabattpreisen | Microsoft Enterprise Agreement |
| **Named User / pro Benutzer** | Die Lizenz ist an eine Person gebunden | M365 |
| **Pro Gerät** | Die Lizenz ist an ein Gerät gebunden | Windows OEM |
| **Concurrent / Floating** | Eine maximale Anzahl gleichzeitiger Nutzer | CAD-Software, MATLAB-Netzwerklizenzen |
| **Pro Kern / Server** | Abgerechnet nach CPU-Kernen | Windows Server, SQL Server |
| **OEM** | Gebunden an die beim Kauf mitgelieferte Hardware | Windows auf einem neuen Laptop |
| **Campus- / Education-Lizenz** | Vergünstigt für Schulen und Lernende, keine kommerzielle Nutzung | Office 365 A1 der TBZ, JetBrains Education |

## Freeware, Shareware & Co.
| Modell | Beschreibung | Beispiel |
|---|---|---|
| **Freeware** | Gratis nutzbar, aber **nicht** quelloffen und Veränderung nicht erlaubt | Adobe Reader, Skype |
| **Shareware / Trial** | Gratis testen (zeitlich oder funktional eingeschränkt), danach bezahlen | WinRAR |
| **Freemium** | Grundversion gratis, Zusatzfunktionen kostenpflichtig | Spotify, Dropbox |
| **Adware** | Gratis, finanziert durch Werbung | diverse Apps |
| **Public Domain** | Kein Urheberrecht bzw. darauf verzichtet, alles ist erlaubt | SQLite |

## Open Source / Freie Software
Der **Quellcode ist offen** und darf eingesehen, verändert und weitergegeben werden. Die vier Freiheiten der Free Software Foundation lauten: Software verwenden, studieren, verbreiten und verbessern.

| Lizenz | Typ | Bedeutung | Beispiel |
|---|---|---|---|
| **GPL** (GNU General Public License) | **Copyleft (stark)** | Abgeleitete Werke müssen wieder unter der GPL veröffentlicht werden («viral») | Linux-Kernel, GIMP |
| **LGPL** | Copyleft (schwach) | Bibliotheken dürfen auch in proprietärer Software verwendet werden | FFmpeg (Teile) |
| **MPL** | Copyleft (schwach, dateibasiert) | Nur geänderte Dateien müssen offen bleiben | Firefox |
| **MIT** | **Permissiv** | Fast alles erlaubt, nur Copyright-Hinweis beibehalten | jQuery, Node.js, VS Code (Quellcode) |
| **Apache 2.0** | Permissiv | Wie MIT, zusätzlich mit Patentklausel | Android, Kubernetes |
| **BSD** | Permissiv | Ähnlich wie MIT | FreeBSD |

## Creative Commons (für Inhalte wie Bilder, Texte, Musik)
Bausteine: **BY** (Namensnennung), **SA** (Weitergabe unter gleichen Bedingungen), **NC** (nicht kommerziell), **ND** (keine Bearbeitung), dazu **CC0** (gemeinfrei).
Beispiel: Wikipedia steht unter CC BY-SA.

## Bedeutung für die Praxis
- **Lizenzmanagement** (Software Asset Management): Unterlizenzierung ist eine Urheberrechtsverletzung und führt zu Nachzahlungen, Bussen und Imageschaden. Hersteller wie Microsoft führen Audits durch.
- Bei Open Source in eigenen Produkten **Copyleft beachten**: Wer GPL-Code in kommerzielle Software einbaut, muss unter Umständen den eigenen Code offenlegen.
- Education-Lizenzen dürfen nicht für kommerzielle Projekte verwendet werden.
