# Gefahren im Internet – Begriffe

| Begriff | Erklärung | Schutz |
|---|---|---|
| **Malware** | Oberbegriff für Schadsoftware jeglicher Art | Virenschutz, Updates, keine unbekannten Dateien öffnen |
| **Virus** | Hängt sich an Dateien oder Programme an und verbreitet sich, wenn sie ausgeführt werden. Braucht einen Wirt. | Antivirus, Vorsicht bei Anhängen |
| **Wurm** | Verbreitet sich selbstständig über Netzwerke und Sicherheitslücken, ohne Wirt | Updates, Firewall |
| **Trojaner** | Tarnt sich als nützliches Programm und öffnet im Hintergrund Hintertüren oder stiehlt Daten | Nur Software aus vertrauenswürdigen Quellen |
| **Ransomware** | Verschlüsselt Daten und fordert Lösegeld | **Offline-Backups**, Updates |
| **Spyware** | Spioniert das Nutzerverhalten aus (Tastatureingaben, Browserverlauf) | Antivirus, App-Berechtigungen prüfen |
| **Adware** | Blendet ungewollt Werbung ein | Adblocker, seriöse Downloadquellen |
| **Keylogger** | Zeichnet Tastatureingaben auf, zum Beispiel Passwörter | MFA, Antivirus |
| **Rootkit** | Versteckt sich tief im System und verschleiert die Präsenz anderer Malware | Secure Boot, im Notfall System neu aufsetzen |
| **Botnetz** | Netzwerk gekaperter Geräte, die ferngesteuert werden (z. B. für DDoS oder Spam) | Updates, Standardpasswörter ändern (IoT) |
| **Phishing** | Gefälschte E-Mails oder Websites, mit denen Zugangsdaten abgefischt werden | Absender und URL prüfen, MFA |
| **Spear-Phishing** | Gezieltes Phishing auf eine bestimmte Person oder Firma | Sensibilisierung, Rückfrage über einen anderen Kanal |
| **Smishing / Vishing** | Phishing per SMS bzw. per Telefonanruf | Keine Links in SMS anklicken, zurückrufen |
| **Social Engineering** | Menschen werden manipuliert, damit sie Informationen preisgeben (z. B. Fake-Support, CEO-Fraud) | Schulung, gesunde Skepsis |
| **Spam** | Unerwünschte Massen-E-Mails | Spamfilter |
| **Scareware** | Falsche Warnmeldungen («Ihr PC ist infiziert!»), die zum Kauf drängen | Ignorieren, Fenster schliessen |
| **DoS / DDoS** | Ein Dienst wird durch Überlastung lahmgelegt (bei DDoS von vielen Quellen aus) | CDN, DDoS-Schutz beim Provider |
| **Man-in-the-Middle** | Ein Angreifer schaltet sich zwischen zwei Kommunikationspartner, z. B. in einem offenen WLAN | HTTPS, VPN |
| **Identitätsdiebstahl** | Missbrauch fremder Personendaten, um im fremden Namen zu handeln | Datensparsamkeit, MFA |
| **Drive-by-Download** | Malware wird schon beim blossen Besuch einer Website heruntergeladen | Browser und Plugins aktuell halten |
| **Zero-Day-Exploit** | Ausnutzen einer Lücke, die dem Hersteller noch nicht bekannt ist | Defense in Depth, schnelle Updates |
| **Cybermobbing** | Belästigung, Bedrohung oder Blossstellung über digitale Kanäle | Beweise sichern, melden, blockieren |
| **Sextortion** | Erpressung mit (angeblichen) intimen Bildern | Nicht zahlen, Anzeige erstatten |
| **Fake News** | Gezielte Falschinformationen | Quellen prüfen |
| **Doxing** | Persönliche Daten einer Person werden recherchiert und veröffentlicht | Datensparsamkeit in sozialen Netzwerken |

Anlaufstelle in der Schweiz: **Bundesamt für Cybersicherheit (BACS)**, Meldeformular unter report.ncsc.admin.ch.
